# 이동형 도로 관제 (스냅샷 방식)

안드로이드 휴대폰이 몇 초마다 사진을 올리고, 로그인한 직원이 웹에서 실시간으로 확인한다.
요구사항은 [REQUIREMENTS.md](REQUIREMENTS.md) 참고.

## 화면
| 주소 | 누가 | 내용 |
|---|---|---|
| `/` | 직원 | 분할 화면, 클릭하면 크게 보기 + 디지털 줌 |
| `/admin` | 관리자 | 카메라 추가·키 발급(QR), 계정 일괄 생성·차단, 설정 |
| `/cam` | 거치한 휴대폰 | 송출 화면 (관리자가 준 QR/링크로 접속) |

## 로컬 실행
```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
처음 실행하면 콘솔에 초기 관리자 계정(`admin`)과 임시 비밀번호가 찍힌다. 첫 로그인 때 비밀번호를 바꿔야 한다.
환경변수 `CCTV_ADMIN_USER`, `CCTV_ADMIN_PASSWORD`로 미리 정할 수도 있다.

## 운영 흐름
1. 관리자: `/admin` → 계정 탭에서 사번 목록 붙여넣기 → 일괄 생성 (초기 비밀번호 = 사번)
2. 관리자: 카메라 추가 → 나온 QR을 거치할 휴대폰으로 찍기
3. 휴대폰: Chrome에서 열린 송출 화면 → 충전기 연결 → "송출 시작"
   - 권장: Chrome 메뉴 → "홈 화면에 추가"로 설치, 안드로이드 "앱 고정"으로 화면 잠금
4. 직원: `/` 접속 → 사번 로그인 → 첫 로그인 시 비밀번호 변경

## 클라우드 배포
네이버 클라우드 기준 단계별 안내는 [DEPLOY.md](DEPLOY.md). 설치는 `deploy/setup.sh` 한 번으로 끝난다 (Caddy가 HTTPS 자동 처리).
스냅샷은 서버 메모리에 두므로 반드시 **워커 1개**로 실행한다.

## 알려진 한계 / 다음 단계
- 분할 화면은 서버가 만든 640px 썸네일을, 크게 보기는 원본을 받는다.
  로컬 부하 시험에서 500명 기준 약 175Mbps, 오류 0건 (`loadtest/loadtest.py`). 실제 서버에서 다시 재야 한다.
- 송출 페이지는 화면이 꺼지거나 다른 앱으로 넘어가면 멈춘다. 화면 꺼짐 방지와 앱 고정으로 운영한다.
- 서버를 재시작하면 마지막 사진이 사라진다 (다음 업로드 때 바로 복구됨).
