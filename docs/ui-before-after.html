도로 관제 UI 전후 비교

같은 시험 데이터(카메라 6대 중 4대 송출, 주의 공지)로 휴대폰(375px)과 PC(1280px)에서 찍었습니다. 어두운 테마는 그대로 유지했습니다.

관제 화면 · 휴대폰

변경 전
변경 후
  • 카메라 6대가 한 화면에 들어옴 (전: 2.5대만 보이고 스크롤)
  • 상단 버튼 3개 → ☰ 메뉴 하나로 정리, 줄바꿈 없음
  • 초록 점만 있던 연결 표시 → '실시간' 글자 칩
  • 카메라마다 갱신 시각 점(초록=정상, 노랑=늦음, 빨강=끊김)
  • 꺼진 카메라는 검은 큰 칸 대신 아래에 작게 모음
  • '송출 중 4 / 6' 요약, 2열/1열 보기 전환

크게 보기 · 휴대폰

변경 전
변경 후
  • 상단 버튼 2줄 → 닫기 · 제목 · 몇 번째(1/4)만
  • 휴대폰에서는 ＋/－ 버튼 숨김 (두 손가락 확대가 더 편함)
  • 옆으로 밀어서 다음 카메라로 넘기기 추가
  • 마우스 기준 안내('휠', '더블클릭') → 터치 기준 안내, 3.5초 뒤 사라짐
  • 확대했을 때만 '원래 크기' 버튼 표시

관제 화면 · PC

변경 전
변경 후
  • 카메라 이름·위치·갱신 시각을 사진 밖 아래 줄로 옮겨 사진을 가리지 않음
  • 꺼진 카메라는 목록 아래로 분리
  • 공지 배너를 둥근 카드로 정리

관리자 · 카메라 표 (PC)

변경 전
변경 후
  • 최신 화면 썸네일 칸 추가 → 현장 설치 때 각도 바로 확인
  • 버튼 5개 → 수정 + ⋯ 메뉴 (회전·비활성화·키 재발급·삭제)
  • 상태 칸에 온라인 + 충전 끊김 + 배터리 부족을 한 번에, 배터리 칸 중복 제거
  • 브라우저 기본 팝업 → 화면 디자인에 맞춘 확인 창 (삭제는 빨간 버튼)
  • 오류도 팝업 대신 하단 알림으로

관리자 · 휴대폰

변경 전
변경 후

  • 현장에서 휴대폰으로 카메라 상태·썸네일 확인 가능

송출 화면 (거치 휴대폰)

변경 전
변경 후
  • 상태를 색 막대로 크게 (초록 송출 중 / 노랑 대기 / 빨강 문제) → 멀리서도 확인
  • 📐 화각 맞추기: 전체 화면 미리보기 + 3분할 안내선 → 도로를 가운데로
  • 시작 전 체크리스트 (충전기, 가로 거치, 화면 유지)
  • 숫자 정보를 칸으로 정리, 기록은 접어서 숨김
